# Portal Showcase — анимация портала для Roblox Studio

Кинематографичная анимация энергетического портала, полностью сделанная кодом:

- три светящихся кольца-гироскопа, по которым бежит волна цвета;
- раскалённое ядро с энергетической оболочкой и вращающейся «гладью» портала;
- вихрь светящихся шариков со шлейфами;
- мерцающие молнии из ядра;
- ударные волны со вспышкой света;
- кино-заставка: пролёт камеры по дуге, чёрные полосы, размытие фона, тряска и надпись.

## Как поставить

1. Открой свою игру в Roblox Studio.
2. В **Explorer** найди `StarterPlayer` → `StarterPlayerScripts`.
3. Нажми `+` → **LocalScript**.
4. Скопируй весь код из [`PortalShowcase.client.lua`](PortalShowcase.client.lua) и вставь в этот скрипт.
5. Для максимального качества выбери `Lighting` и в **Properties** поставь `Technology = Future`.
6. Нажми **Play**.

Портал появится перед персонажем, и сразу запустится заставка. Чтобы посмотреть её ещё раз, нажми **P**.

## Настройки

В начале скрипта есть таблица `SETTINGS`:

| Настройка | Что меняет |
|---|---|
| `MainColor`, `AccentColor` | цвета портала |
| `Title` | надпись в заставке |
| `Distance`, `Height` | где появится портал |
| `RingRadius`, `RingSegments` | размер и гладкость колец |
| `OrbCount`, `ArcCount` | количество шариков и молний |
| `ShockwaveInterval` | как часто идёт ударная волна |
| `CinematicDuration` | длина пролёта камеры |
| `ChangeLighting` | `false` — не трогать освещение карты |
